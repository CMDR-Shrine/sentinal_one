I get a lot of spam on my personal email server

SpamAssasin is great but in this time of LLMS, filtering on semantics doesn't work on grammatically correct emails

Instead we must fight fire with fire, harnessing Kev (open source jev) we can classify emails that are potential spam.

Seeing as im self hosting the Kev model, privacy is repected, pretty important in todays age.

This project has ironically been built without use LLMs for lookups or code generation

The kev model will be hosted either on my laptop or my home pc initially for testing
